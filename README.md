# THE INVISIBLE FACTORY

### Industrial Capital Efficiency & Spatial Decision Intelligence Laboratory

> Discover the capacity you already own before investing in the capacity you think you need.

## Project Overview

THE INVISIBLE FACTORY is an independent applied research prototype integrating industrial systems, corporate finance, sustainability and computational decision intelligence through an interactive 2.5D simulation environment.

**Mohd Khairul Ridhuan bin Mohd Fadzil**

## Industrial Problem

Capital expenditure decisions may overlook opportunities to unlock productive capacity within existing industrial assets.

This project explores how operational optimisation, capital allocation and environmental constraints can be evaluated within an integrated decision-support environment.

## Core Research Dimensions

- Industrial capacity and bottleneck analysis
- Corporate financial modelling
- Counterfactual investment simulation
- Capital allocation efficiency
- Energy consumption and sustainability
- Executive decision intelligence
- Transparent and reproducible methodology

## Development Architecture

- Interactive 2.5D isometric simulation
- HTML5, CSS3, JavaScript and SVG
- Modular mathematical decision engine
- Browser-based deployment
- No paid API or external database required

## Scientific Integrity

The initial prototype uses explicitly labelled hypothetical industrial scenarios.

Financial projections are illustrative and do not constitute investment advice. The model is not an empirically validated industrial digital twin.

Software development is AI-assisted, with an emphasis on transparent assumptions, reproducible calculations and documented limitations.
